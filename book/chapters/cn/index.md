# RLHF Book 中文版

本站是 Nathan Lambert 所著 [RLHF Book](https://rlhfbook.com)（*Reinforcement Learning from Human Feedback*）的中文翻译，技术术语保留英文。原书是一本关于 RLHF、偏好微调、reward model、RLVR 以及语言模型后训练的免费在线图书。

翻译随原书更新同步，各章第一行的 `source-commit` 记录其对应的原书版本。翻译问题与改进请到 [ly4096x/rlhf-book](https://github.com/ly4096x/rlhf-book) 提出；英文原版请见 [English version](../../)。
